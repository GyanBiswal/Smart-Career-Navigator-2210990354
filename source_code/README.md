# Smart Career Navigator

Smart Career Navigator is an AI-powered career guidance system designed to bridge the gap between student skills and industry requirements.

The project analyzes resumes and job descriptions using Natural Language Processing (NLP) and semantic AI models to identify missing skills, calculate a Career Readiness Score, and recommend personalized learning paths.

The system uses NLP techniques with spaCy to extract important skills such as programming languages, frameworks, tools, and soft skills from unstructured text. It then uses BERT-based embeddings and cosine similarity to compare resume skills with job requirements, even when the wording differs.

Key Features:

* Resume Parsing using NLP
* Skill Extraction from resumes and job descriptions
* Semantic Skill Matching using BERT
* Career Readiness Score
* Skill Gap Identification
* Personalized Learning Recommendations

Tech Stack:

* React.js
* Node.js
* spaCy
* BERT
* MongoDB

The main objective of this project is to help students become more industry-ready through intelligent skill gap analysis and AI-driven career guidance.

“Transforming career guidance from static recommendations to intelligent career optimization.”
